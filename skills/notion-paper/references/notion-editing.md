# Notion 编辑契约

## 当前任务状态

在 `paper-start` 后维护任务内状态，不写入本地文件或 Notion 属性：

```yaml
paper_title:
pdf_reference:
paper_page_id:
reading_root_page_id:
section_map:
active_section_title:
active_section_page_id:
```

固定章节命令从 `section_map` 取页面 ID。`technology-run` 和 `section-run` 只在当前论文的精读目录中匹配。不要搜索其他论文或整个工作区。

新任务或上下文中缺少状态时，要求重新 `paper-start`；不要用数据库状态恢复当前论文。

## 写入前

1. 在任务第一次内容写入前尝试读取 `notion://docs/enhanced-markdown-spec`。
2. 若资源可读，记录本任务使用完整规范。
3. 若返回 `Unknown resource` 或资源接口不可用，先确认 Notion 的 fetch/update/create 工具仍可调用，再读取 [notion-markdown-fallback.md](notion-markdown-fallback.md)，记录本任务使用安全回退模式。不要因规范资源缺失而拒绝所有写入。
4. fetch 目标页面并保存完整结构。
5. 标记所有子页面、mention、图片、附件、表格和公式。
6. 使用最小范围更新。
7. 不设置允许删除子内容的危险参数。

若 Notion 内容工具本身鉴权失败、连接失败或不可用，停止写入。若只有某个高级块的语法无法确认，只跳过该高级块并在对话中说明；继续执行不依赖该语法的安全写入。

## 润色稿生命周期

章节运行时保留原始笔记，在页面末尾追加：

```markdown
# 润色稿（待确认）
```

把完整润色稿放在此标题下。

如果页面已有且仅有一份该标题：

- 更新其内容，不追加第二份。
- 把用户对旧润色稿的手动修改视为新的输入。

如果出现多份同名草稿或边界无法确定，停止写入并在对话中说明。

润色稿应包含最终提交后仍需保留的图片、表格、公式、链接和 page mention，并可重新安排位置。原始笔记在提交前保持不变。

## 知识子页面

只有显式要求时创建：

1. 以当前章节作为 parent 创建 `📌` 子页面。
2. 直接写入正式解释，不创建润色稿包装。
3. 在当前章节保留子页面入口。
4. 更新“论文精读”目录，把新子页的 mention 与所属章节并排展示。
5. 保留目录中已有 columns、页面和 mention。
6. 创建后 fetch 子页、当前章节和精读目录进行验证。

若无法安全修改现有 columns，先保留子页并在对话中说明目录 mention 未完成；不要破坏原布局。

## `section-commit`

显式命令授权删除当前章节的原始笔记与草稿包装，但不授权删除子页面或媒体。

执行：

1. 要求 `active_section_page_id` 存在。
2. fetch 当前章节。
3. 确认恰好存在一份 `# 润色稿（待确认）`。
4. 提取标题下经用户修改的全部内容。
5. 收集必须保留的子页面、图片、附件和 page mention。
6. 如果某个子页面只存在于原始区域而未出现在润色稿，把其 page block 或 mention 合并到最终内容的合理位置。
7. 以润色稿正文替换页面内容，并移除草稿标题。
8. 若 Notion 警告会删除子页面，停止；不要自动允许删除。
9. fetch 页面验证：
   - 原始笔记已移除；
   - 草稿标题已移除；
   - 最终正文存在；
   - 子页面与必要媒体仍存在。

不要改变论文状态、Completion Date、首页总结或其他章节。

## 状态更新

- `paper-start`：不修改状态。
- `paper-init`：设置 `Unread`。
- 当前论文第一次执行任意章节运行：从 `Unread` 更新为 `In Progress`。
- 后续章节运行和 `section-commit`：不修改状态。
- 不实现 `paper-complete`。

## 运行报告

章节运行报告：

- 即时问题及回答摘要。
- 每个答案是否融入正文及理由。
- 公式补充。
- 子页创建和并排 mention。
- 保留问题数量。
- 与 PDF 不一致的修正。
- 草稿写入和回读验证。

提交报告：

- 当前章节标题。
- 最终内容已替换。
- 保留的子页和媒体。
- 回读验证结果。

## 异常处理

- PDF 缺失：不能执行章节运行或初始化。
- 论文条目重名：停止并列出候选。
- 章节标题无法唯一匹配：停止并列出当前论文内候选。
- 无活动章节：拒绝 `section-commit`。
- 无草稿或多份草稿：拒绝提交。
- 公式无法确认：只在对话说明。
- 外部资料与论文冲突：在对话指出，不静默写入。
- Notion 写入可能删除子内容：停止。
- Markdown 规范资源返回 `Unknown resource`，但 Notion 内容工具可用：进入安全回退模式，不把它当作整体写入阻断。
- 安全回退模式无法确认某个高级块语法：跳过该块、报告限制，并继续其他普通文本写入。
