# Notion Markdown 安全回退

仅当 `notion://docs/enhanced-markdown-spec` 返回 `Unknown resource` 或当前 MCP 客户端不支持资源读取、但 Notion 内容工具仍可用时采用本规范。它不是完整 Enhanced Markdown 规范，只覆盖论文笔记所需的最小安全写入子集。

## 权威顺序

按以下顺序决定语法：

1. 可读取的 `notion://docs/enhanced-markdown-spec`。
2. 当前 Notion 工具的输入 schema 与工具说明。
3. 对目标页执行 fetch 后返回的原始内容表示。
4. 本文件定义的最小安全子集。

高优先级来源与本文件冲突时，使用高优先级来源。

## 可直接新建的内容

只主动生成以下普通结构：

- 普通段落。
- `#`、`##`、`###` 标题。
- 使用 `- ` 的无序列表。
- 使用 `1. ` 的有序列表。
- 页面中已经验证可用的普通 Markdown 链接。

润色稿标题 `# 润色稿（待确认）` 属于安全结构。不要为了视觉效果主动增加未验证的颜色、HTML、columns、callout 或其他扩展标记。

## 必须保留原样的内容

对 fetch 返回的以下结构，只能复制或整体移动其原始表示，不得凭记忆重建、改写包裹标签或猜测属性：

- 子页面与数据库块。
- page、database、user 与 date mention。
- 图片、文件和附件。
- 表格。
- 公式块。
- callout、toggle、columns 和其他增强块。

保留子页面时，使用 fetch 返回的准确 `<page url="...">`；保留数据库时使用准确 `<database url="...">`。不要自行拼接 URL 或 ID。

## 新增高级内容

- 新公式：只有 PDF 公式内容和当前页面已返回的公式语法都可确认时才写入；否则在对话中给出公式与含义，标记该公式未写入，但继续生成其余润色稿。
- 新知识子页：可以使用 Notion create 工具创建普通标题与正文；父级 ID 必须来自当前任务状态。目录中的 columns 或 mention 只有在 fetch 返回了可复用的准确表示时才修改。
- 初始化 callout、toggle 或 columns：先 fetch 初始化规范页和已完成示例，复用其准确表示。无法确认时停止该高级结构的创建并报告，不影响独立的普通文本写入。

## 安全更新方式

1. 写入前 fetch 目标页面。
2. 页面没有润色稿时，优先在末尾插入安全结构和完整润色稿。
3. 页面已有唯一润色稿时，优先精确更新该区域，不重新提交无关内容。
4. 仅在 `section-commit` 中允许整页替换；替换内容必须显式带回所有需保留的子页、媒体、附件和 mention。
5. 不启用允许删除子内容的参数。
6. 写入后再次 fetch，验证目标文本、唯一草稿、子页和媒体。

## 停止边界

- 规范资源缺失不是停止条件。
- Notion 内容工具鉴权失败、连接失败或不可用时停止。
- 写入会删除子页、数据库或媒体时停止。
- 只有无法确认语法的高级块需要局部停止；普通标题、段落、列表和可验证的已有结构仍可继续写入。
